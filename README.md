# Post Office Currency Converter

A React Native currency converter built with Expo + TypeScript.

## Prerequisites

- Node.js (v19+) and npm
- The **Expo Go** app on your phone (App Store / Play Store)
- Mac and phone on the **same Wi-Fi network**

## Run it

```bash
npm install
npm run dev
```

`npm run dev` boots both the mock API (`:8000`) and the Expo dev server in one terminal. Scan the QR code with your phone's camera and open in Expo Go. The app auto-detects the dev machine's LAN IP (via `expo-constants`), so no manual IP config is needed.

## Tests

```bash
npm test
```
